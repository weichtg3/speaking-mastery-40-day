# Speaking Mastery — 40-Day Dual Program

A GitHub-ready, self-paced course requiring **20–30 minutes/day for 40 days**.

## Included
- 40 Articulation sessions (10–15 min/day)
- 40 STAGE-style communication sessions (10–15 min/day)
- Daily exercises + transfer practice
- Reading, audio and video references
- Checkpoints on Days 1, 10, 20, 30 and 40
- Progress tracker and group-sharing guide
- Curated resource library

## Philosophy
The goal is not to erase anyone's accent or make everyone sound alike. The goals are **intelligibility, confidence, audience connection, organization, and effective delivery**.

This is an independent educational program, not an official STAGE Academy product and not medical/speech-language therapy.


## GitHub Pages Website

A polished web version is included in `site/`, together with an automated GitHub Pages deployment workflow.

➡️ **[GitHub Pages setup](GITHUB_PAGES.md)**

Once pushed to GitHub, set **Settings → Pages → Source → GitHub Actions**. Every push to `main` deploys automatically.

No Node/npm build is required.
